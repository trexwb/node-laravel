# 2026-04-01

## 技术提升指导报告

对 node-laravel 框架进行了深度代码审阅，发现以下关键问题：

### P0 严重问题（竞态条件）
1. `UsersService.updateToken` 第60行 `UsersModel.modifyById` 缺少 `await`，导致 token 竞态
2. `UsersService.clearUserCache` 内 6 个 `CacheService.forget` 全部缺少 `await`
3. `UsersModel.buildQuery` keywords 搜索的 SQL 字段名格式错误（反引号包裹了 `tableName.field`）

### 主要建议
- 启用 ESLint `@typescript-eslint/no-floating-promises` 规则（可自动检测 await 遗漏）
- 引入 Vitest 建立测试体系（项目用 ESM，Jest 不友好）
- 减少 Controller 里的 `(req as any)` 强转（express.d.ts 已声明好了）
- 缓存失效改为精确失效，不用全量 `flushallCache`

### 框架亮点
- 四段式错误码体系设计非常专业
- BaseModel 封装完整，软删除/分页/排序统一
- Cluster 感知 + CacheService 多驱动 + Handler 分层错误处理都很成熟
