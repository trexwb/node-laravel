## 📘 Node-Laravel 开发手册

> 本手册面向在 Node-Laravel 框架上进行业务开发的工程师与 AI Agent。
> 所有 AI Agent 编写代码前，**必须**先阅读根目录 [AGENTS.md](../AGENTS.md) 开发规范。

### 1. 项目架构概览

框架采用 Laravel 风格分层架构，确保逻辑清晰且易于扩展：

* **`src/app/Http/Controllers`**: 控制器层，分为 `Front/`（Web 前台）、`Api/`（API 网关）、`WebSocket/`（WS 频道）。
* **`src/app/Http/Middleware`**: 中间件（鉴权 / 签名 / 加解密 / 限流 / 追踪）。
* **`src/app/Models`**: 数据库模型，基于 Objection.js（Eloquent 风格），继承 `BaseModel`。
* **`src/app/Services`**: 业务服务层，承载业务逻辑、缓存处理等核心逻辑，不接触 req/res。
* **`src/app/Foundation`**: 轻量服务容器 `Container`，统一管理依赖注入。
* **`src/app/Helpers`**: 助手函数（`ControllerHelper / QueryHelper / FilterHelper` 等）。
* **`src/app/Jobs` / `Events` / `Listeners`**: 异步任务、系统事件与监听器。
* **`src/bootstrap`**: 启动引导（配置加载、路由加载、集群、事件总线、调度）。
* **`src/routes`**: 路由定义：`web.ts / api.ts / console.ts / event.ts / channels.ts`。

### 2. 路由与控制器（核心）

#### 2.1 路由文件职责

| 路由文件 | 挂载前缀 | 职责 |
| --- | --- | --- |
| `src/routes/web.ts` | `/` | 前台（Web）路由 + 静态资源 + SPA 代理（由原 `front.ts` 更名而来，对应 Laravel `web.php`） |
| `src/routes/api.ts` | `/api` | API 网关路由（统一鉴权 / 签名 / 加解密 / 限流 / 追踪） |
| `src/routes/console.ts` | `/console` | 控制台路由 + SPA 代理 |
| `src/routes/event.ts` / `src/routes/channels.ts` | - | 事件订阅 / WebSocket 频道 |

#### 2.2 控制器分层规范

**瘦控制器、厚服务层**：控制器只做参数解析、调用服务、返回响应；业务逻辑放在 Service。

```typescript
// src/app/Http/Controllers/Front/ExampleController.ts（Web 控制器示例）
import { Container } from '#app/Foundation/Container'
import { ExampleUserService } from '#app/Services/Example/ExampleUserService'
import type { Request, Response } from 'express'

export class ExampleController {
  static async index(_req: Request, res: Response) {
    const service = Container.resolve<ExampleUserService>('example.userService', () => new ExampleUserService())
    const users = await service.list()
    return res.success(users)
  }

  static async show(req: Request, res: Response) {
    const service = Container.resolve<ExampleUserService>('example.userService', () => new ExampleUserService())
    const user = await service.find(Number(req.params.id))
    if (!user) return res.error(404000200001, 'user not found')
    return res.success(user)
  }

  static async store(req: Request, res: Response) {
    const service = Container.resolve<ExampleUserService>('example.userService', () => new ExampleUserService())
    const user = await service.create(req.body)
    return res.success(user, 201)
  }
}
```

#### 2.3 路由注册

```typescript
// src/routes/web.ts（注意：注册在 /{*splat} 通配代理之前！）
import { ExampleController } from '#app/Http/Controllers/Front/ExampleController'
router.get('/example', ExampleController.index)
router.get('/example/:id', ExampleController.show)
router.post('/example', ExampleController.store)
```

```typescript
// src/routes/api.ts（注册在网关中间件链之后，自动继承统一安全能力）
import { ExampleUserController } from '#app/Http/Controllers/Api/ExampleUserController'
router.get('/example/users', ExampleUserController.index)
router.get('/example/users/:id', ExampleUserController.show)
```

#### 2.4 依赖注入（Container）

```typescript
import { Container } from '#app/Foundation/Container'

// 注册
Container.bind('example.userService', () => new ExampleUserService())
// 单例
Container.singleton('cache', () => new CacheService())
// 实例
Container.instance('foo', someInstance)
// 解析（fallback 兜底）
const service = Container.resolve<ExampleUserService>('example.userService', () => new ExampleUserService())
```

> 完整示例见：`src/app/Services/Example/ExampleUserService.ts`、`src/app/Http/Controllers/Front/ExampleController.ts`、`src/app/Http/Controllers/Api/ExampleUserController.ts`。

### 3. 数据库与模型 (ORM)

#### 创建模型

所有模型应继承 `BaseModel`。框架会自动处理 `snake_case` (DB) 到 `camelCase` (JS) 的转换。

```typescript
// src/app/Models/Users.ts
import { BaseModel } from '#app/Models/BaseModel'

export class Users extends BaseModel {
  id!: number
  username!: string

  static get tableName() {
    return `${process.env.DB_PREFIX}users`
  }
}
```

#### 数据库查询

```typescript
const user = await Users.query().findById(1)
const activeUsers = await Users.query().where('isActive', true).orderBy('createdAt', 'desc')
```

### 4. 缓存系统 (Cache)

支持 `file`、`redis` 驱动，通过 `.env` 中的 `CACHE_DRIVER` 切换（生产环境必须 redis）。

```typescript
import { CacheService } from '#app/Services/Cache/CacheService'

// 存取数据（带 3600 秒有效期）
await CacheService.set('key', { name: 'Gemini' }, 3600)
const data = await CacheService.get('key')

// 记住缓存（若不存在则执行回调并存储）
const users = await CacheService.remember('all_users', 600, async () => {
  return await Users.query()
})
```

### 5. 安全与加解密 (Security)

框架内置全链路安全方案，通过中间件在 `src/routes/api.ts` 中配置。

| 功能 | 环境变量 | 中间件 | 说明 |
| --- | --- | --- | --- |
| **请求签名** | `VERIFY_SIGNATURE=true` | `verifySignature` | 校验 API 请求的合法性（HMAC-SHA256）。 |
| **数据解密** | `REQUEST_ENCRYPT=true` | `decryptRequest` | 自动解密前端 POST 的 AES 密文。 |
| **响应加密** | `RETURN_ENCRYPT=true` | `encryptResponse` | 自动加密返回给前端的数据。 |
| **网关鉴权** | - | `authenticateSecret` | appId / appSecret 校验（HMAC-SHA256 + 时间戳 + nonce）。 |
| **Token 鉴权** | - | `authenticateToken` / `optionalAuth` | Bearer Token 校验 / 可选鉴权。 |
| **全链路追踪** | - | `traceId` | 注入 `req.id`（TraceId）。 |

### 8. 开发规约

1. **路径别名**：使用 `#` 子路径（`#app/*`、`#bootstrap/*`、`#config/*`、`#database/*`、`#public/*`、`#resources/*`、`#routes/*`、`#storage/*`、`#types/*`、`#utils/*`），**禁止**相对路径跨层引用。
2. **文件头注释**：新建 / 修改文件必须带文件头注释（模板见 `AGENTS.md` 第 5 节），`@FilePath` 使用 `node-laravel/...` 相对路径。
3. **响应规范**：控制器中必须使用 `res.success(data, code?, msg?)` 或 `res.error(code, msg)`，确保前端收到统一的 JSON 格式。
4. **类型安全**：提交前必须 `npx tsc --noEmit` 0 错误；严禁 `any`、未使用变量 / 参数。
5. **时间处理**：模型返回的时间默认通过 `BaseModel` 转换为 `TIME_ZONE` 环境指定的时区字符串。
6. **提交前**：`npm run build` 必须通过，并同步更新 `docs/version/` 变更日志。
