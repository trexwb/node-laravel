## 一、框架起源

`node-laravel`（Node Laravel Style Framework）由**史特牢（STL）** 项目后端提取而来。在提取过程中剥离了全部业务专属逻辑（用户、密钥、调度、配置、订单、支付等），将通用的 Laravel 风格架构能力沉淀为可复用的 Node.js 框架，供史特牢（STL）、仟标、大美等多个企业及系统复用。

---

## 二、从史特牢（STL）提取落地的关键变更

### 2.1 移除业务专属代码
- 移除业务模型：`UsersModel / RolesModel / PermissionsModel / SecretsModel / SchedulesModel / ConfigsModel / JobsModel / ServersModel / *LogsModel` 等
- 移除业务控制器：`AuthorizeController / UsersController / SecretsController / SchedulesController`
- 移除业务服务：`UsersService / SecretsService / SchedulesService / ImageService / CacheSqliteDriver`
- 移除业务路由：`routes/apis/console/*`、`routes/apis/front/*`、`routes/rpc.ts`、`routes/rpcs/*`
- 移除业务数据库迁移与种子：`src/database/migrations/*`、`src/database/seeds/*`

### 2.2 新增框架级能力
- 新增**轻量服务容器**：`src/app/Foundation/Container.ts`（`bind / singleton / instance / resolve`）
- 新增**全局类型声明**：`src/types/*.d.ts`（`framework / helpers / express / http / models / query / errors / events / jobs / rpc / cache / casts / utils / authorize`）
- 新增**工具集**：`src/app/Helpers/*`（`cryptoTool / logger / query / requestContext / readKey / mask / format / amount / string / treeBuilder / hashPassword / validation`）
- 新增 **Events / Listeners 事件系统**：`src/app/Events/*`、`src/app/Listeners/*`、`src/bootstrap/events.ts`
- 新增 **Queue 队列服务**：`src/app/Services/Queue/DatabaseQueueService.ts`、`src/app/Jobs/Job.ts`
- 新增 **RPC 微服务客户端**：`src/app/Services/Rpc/*`（`JsonRpcClient / LoadRpcClients / CircuitBreaker`）
- 新增**中间件**：`TraceId`（全链路追踪）、`OptionalAuth`（可选鉴权）、`ValidateRequest`（请求校验）
- 新增**助手函数**：`src/app/Helpers/*`（`ControllerHelper / QueryHelper / FilterHelper / TransformerHelper / OrmGraphHelper / CacheHelper / LogHandleHelper / StatTypeHelper`）
- 新增**路由加载器**：`src/bootstrap/routeLoader.ts`
- 新增 `src/app/Interfaces/*`、`src/app/Console/Kernel.ts`、`src/app/Exceptions/Handler.ts`（框架级）

### 2.3 工程化改造
- 采用 **`#` 子路径别名**：`package.json` 的 `imports` 字段 + `tsconfig.json` 的 `paths` 双映射（`#app/* #bootstrap/* #config/* #database/* #public/* #resources/* #routes/* #storage/* #types/* #app/Helpers/*`）
- 构建链路：`npm run build = tsc && tsc-alias`（编译后将 `#` 别名转为相对路径）
- 严格 TS 配置：`strict / noImplicitAny / noUnusedLocals / noUnusedParameters / verbatimModuleSyntax / noEmitOnError`
- 安全能力框架化：密钥鉴权、签名验证、请求解密、响应加密等中间件保留为框架级，业务方通过 `Container` 注入 Provider 使用
